# AI Guard 0.3.2 验证记录

交付 `release/AI-Guard-Setup-0.3.2-x64.exe`（产物不入库，`release/` 已在 `.gitignore` 中）。

## 本次变更

启动前置门：在提权启动 worker 之前做一次裸网络预检，未认证网络直接拒绝启动。

修复的是校园网 / 酒店网这类「先连上、再网页认证」网络下的死锁：原启动流程会先装
WFP 规则（只放行内核）、再用 TUN 接管默认路由、再把网卡 DNS 改成 198.18.0.2，
而此时尚未认证，内核自己也出不去 —— 认证页打不开 ⇒ 无法认证 ⇒ 永远出不去。

依据：该网络下日志里「触发断流」为 0 次，确认不是保护误触发，而是链路从源头未建立。

## 已知代价

认证过期时保持 fail-closed 断流（不做自动让路）：校园网会话过期后 AI Guard 仍会维持
断流，需先退出软件完成认证。这是刻意选择，换「保护永不静默消失」。
