# 节点选择、Claude 体检和时区实施计划

用户已确认设计并要求开始。复用现有普通代理组、提权 worker 与 React 页面。

## 约束

- 普通节点只修改普通代理组，通过内核 PUT selector 操作，不重载 TUN。
- Claude 检测固定展示未检测状态，手动体检取真实规则、连接与 claude.ai trace，无法验证显示 unknown。
- 根据住宅出口 IP 通过 HTTPS 查询 IANA 时区，允许人工选择 Windows 时区，点击才修改系统。
- 时区值必须从系统时区列表验证，保存原时区以供恢复。自动时区服务可能覆盖手动设置时明确提示。
- 保留现有 DNS 修复和实时保护。测试不修改用户当前系统时区或真实节点。
